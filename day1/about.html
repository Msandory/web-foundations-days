About QuickNotes

QuickNotes is a lightweight web application designed to help you instantly capture and manage your daily ideas. It provides a clean, distraction-free environment to store important reminders before they slip your mind.

How to use QuickNotes

  1. Navigate to the Home page.
  2. Type your idea into the new note input field.
  3. Click the submit button to add it to your active list.

Features

  • Instant local note creation
  • Clean and responsive HTML5 layout
  • Easy navigation between home and about sections

Keyboard shortcuts

Shortcut Action
Ctrl + N Focus new note input
Ctrl + Shift + Delete Clear all notes
